# Mineral and gem icons

Downloaded from OpenGameArt on 2026-11-17 (Asia/Bangkok).

- CC0 Mineral Icons, collected by AntumDeluge:
  https://opengameart.org/content/cc0-mineral-icons
  Archive: mineral-ocal_20210112.zip
- CC0 Gem Icons, collected by AntumDeluge:
  https://opengameart.org/content/cc0-gem-icons
  Archive: gem-ocal_0.zip
- License: Creative Commons Zero (CC0)
  https://creativecommons.org/publicdomain/zero/1.0/
- Original per-image source links are preserved in mineral-OCAL.txt and gem-OCAL.txt.

The game uses the original 32x32 PNGs stored here, scaled with pixelated rendering.
Copper uses the gold ore icon with a CSS color adjustment; iron and silver share
the silver ore image. All assets load locally without network access.
Mithril and adamantite are fantasy resources. Sale prices and drop rates are game design values.

are not scientific illustrations of each named mineral. No generated images are used.
